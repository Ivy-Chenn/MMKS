# Robot Installation Checklist

## Pre\-Installation Check

**Goal:** Ensure you have all the parts, tools, and correct preparation before touching the lawn\.

### Unboxing and Verification

- Packaging undamaged, seal intact\. 

- Verify all items are present: 

    - mower User manual / quick\-start guide 

    - 3D Vision Module \(Luba Series\)\. 

    - Front Bumper \(Luba2x\)\. 

    - RTK Reference Station and radio antenna\. 

    - Power supply and cables for RTK and charging stations\. 

    - Accessory kit\. 

    - Mounting hardware \(stakes, screws, brackets, pole, etc\.\)\. 

    - Robot\. 

    - Charging station\. 

### Preliminary Checks

- Inspect robots and charging contacts for transport damage\. 

- Verify software/app readiness: customer phone has the Mammotion app installed, account ready\. 

- Confirm internet/Wi\-Fi password available \(2\.4 GHz network for RTK, 5GHz for Robot\)\. 

---

## Mammotion Robot Installation

### Robot Assembly

- \(Luba 2X\) Attach front bumper securely; verify alignment and free movement\. 

- \(Luba Series\) Mount vision module \(camera\) as per manual, ensure connector clicks firmly\. 

- Check cable routing: no pinched or twisted cables\. 

### Charging Station

- Choose a flat, stable, dry surface\. 

- Ensure the station faces open lawn, not walls or fences\. 

- Avoid walls, trees, fences, or metal objects nearby\. 

- Minimum 1\.5 m clearance in front, 0\.5 m on each side\. 

- Connect power supply, check LED indicator\. 

- Fix the charging station to the ground using provided bolts\. 

- Connect power supply and ensure LED indicator is on\. 

- Place the robot on station and verify proper alignment of charging contacts\. 

### RTK Base Station Setup \(if applicable\)

- Place base station in fully open sky area, ideally with 360° horizon\. 

- Mount securely using pole or wall bracket; confirm it’s level and stable\. 

- Connect antenna and power; wait for RTK fixed signal\. 

- Verify robot connection in app and RTK correction signal strength\. 

### Robot Connection

- When the robot powers on, connect it to the Mammotion App: 

    - Bluetooth 

    - Wi\-Fi 

    - Firmware update if required\. 

### Mapping & Calibration

- Document installation \(If allowed\): take photos of charging station and RTK placement\. 

- Start “Mapping Mode” in app\. 

- Drive robot manually or let it auto\-map boundary\. 

- Define zones and no\-go areas \(pools, trees, flowerbeds\)\. 

- Save maps, check boundaries visually on app maps\. 

- Test return\-to\-dock and start of mowing route\. 

### Functional Tests

- Start the first mowing session in a small test zone\. 

- Observe mowing patterns, obstacle avoidance, and turning behavior\. 

- Check obstacle sensors \(camera, ultrasonic, bumper\) react correctly\. 

- Confirm robot resumes and docks for charging when done\. 

### Customer Handover

- Demonstrate app features \(start/stop, scheduling, no\-go zones\)\. 

- Explain emergency stop and manual towing procedure\. 

- Instruct on cleaning and maintenance \(deck, blades, charging contacts\)\. 

- Advise on firmware updates and seasonal storage\.
