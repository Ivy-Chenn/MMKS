    Hardware Troubleshooting

    Drive Board Linkage Issue - Upgrade Failed / Wheels Not Powered / Powers Off After Exit / Battery Not Displayed or 0% / Battery Info Update Failed

    Error Code:

    • 1015 Battery information update failed

    Solution:

    1. Check for the following conditions: the wheels are not powered and have no resistance / the device powers off after leaving the dock / the battery level is not displayed or shows 0 / battery information update failed.
    2. Check for error code 1505. If present, the device needs to be sent in for repair.

    Query Page:

    1. Check the Device Profile and Self-check modules to confirm whether the robot's hardware connections are normal.
    2. Based on the corresponding error code, preliminarily determine the type and possible cause of the robot's fault.

    If not solved: Needs Repair

    Hub Motor - Hub Motor / Hall Sensor Error

    Error Code:

    • 136/146 Left/right rear wheel hub motor sensor fault
    • 134/144 Left/right rear wheel hub motor stopped
    • 133/143 Left/right rear wheel hub motor overcurrent
    • 135/145 Left/right rear wheel Hall sensor error

    Solution:

    1. Confirm whether the device is actually stuck or trapped on an obstacle. If it is not stuck, or the obstacle has been cleared but the error persists, the issue may be a wheel hub motor Hall sensor error / sensor abnormality.
    2. Confirm the actual error code and check whether restarting resolves the issue.

    Hub Motor - Hub Motor Abnormal

    Error Code:

    • 542/574/144/134 Wheel hub motor stall
    • 543/549/575/581/113/389/383/357/351 Wheel hub motor overload
    • 558/590/398/366/141/131/121/111 Wheel hub motor temperature too high
    • 142/132/122/112 Wheel hub motor temperature too low
    • 561/592/593/400/401/369 Wheel hub motor MOS temperature too low
    • 546/547/578/579/387/386/355/354/145/135/125/115 Wheel hub motor Hall sensor abnormal
    • 551/552/583/584/392/391/360/359 Wheel hub motor voltage abnormal
    • 559/591/399/367 Wheel hub motor
    • 560/368 Wheel hub motor MOS temperature abnormal / too high
    • 2821/2826 Wheel hub motor controller communication timeout

    Solution:

    1. Clean any foreign objects tangled on the wheel axle, then power off and restart the device several times.
    2. Manually drive the mower in the app, and check whether the device can move forward, reverse, and turn left / right normally. If it works normally, then the issue only occurs during automatic operation, not during manual control.

    1. Check the Device Profile and Self-check modules to confirm whether the robot's hardware connections are normal.
    2. Based on the corresponding error code, preliminarily determine the type and possible cause of the robot's fault.

    Solar Panel - Solar Panel Cannot Power RTK Normally

    Solution:

    1. Determine whether the RTK indicator is normal under other power supply methods (charging station power, RTK adapter power, Type-C power). If none of them is normal, replace the RTK.
    2. If it is normal, check whether the solar panel lights up properly, and check the color and status of the indicator (green flashing means battery is above 50%, which is the normal state; yellow flashing means 10-50%; red flashing means below 10%; blue flashing means the solar panel is charging; the indicator is off). If it is not normal, replace the solar panel. Also, use the solar panel when there is sufficient sunlight.

    If not solved: Needs Repair

    Solar Panel - Solar Panel Light Effect

    Solution:

    1. After 5-15 seconds of direct sunlight (depending on light intensity), the device will automatically power on and stay on, with a flashing blue indicator. Short-press the power button to check the current battery indicator.
    2. If there is no sunlight, long-press the power button to power on. After powering on, the indicator will be solid green or yellow for a few minutes, then slow-flash. After slow-flashing for a few minutes, the device will power off and the indicator will go off if the RTK is not powered or the device is not exposed to sunlight.
    3. When the solar panel indicator is green, the approximate power supply duration for the base station can be confirmed (under normal conditions, it can support about one day of power supply).

    If not solved: Needs FAE Upgrade

    Noise - Cutter Disc Start-Up Noise / Mowing Noise / Hub Motor Noise

    Solution:

    1. In manual mode, drive the mower forward (do not start the cutter, do not mow, just control the direction to move the mower) and check whether there is any abnormal noise.
    2. Clean the grass tangled in the cutter disk, and in manual mode select "Manual Mowing" to check whether the noise still exists (i.e., cutter-on test).
    3. Verify and ensure that the adapter bracket nut is tight. Remove the cutter disk and check whether the noise still exists.
    4. If there is no noise after removing the cutter disk, check whether the cutter disk is worn and whether any screws are loose.
    5. If the noise still exists after replacing the cutter disk / screws, and the noise comes from the wheel hub motor, listen carefully to identify which wheel. With the machine powered off, check the wheel's exterior for damage and manually rotate the wheel to see whether it rotates smoothly. If not, clear any grass tangled in the wheel hub and try again. If the noise persists, it is most likely a wheel hub motor noise.
